# Local web fonts

These WOFF2 subsets are bundled locally so the guide does not depend on a third-party font service at runtime.

- Source Serif 4 — Latin, weights 400–700; Fontsource package 5.3.1; see `LICENSE-source-serif-4.txt`.
- IBM Plex Sans — Latin, weights 400–700; Fontsource package 5.3.0; see `LICENSE-ibm-plex-sans.txt`.
- IBM Plex Mono — Latin, weights 400 and 600; Fontsource package 5.3.0; see `LICENSE-ibm-plex-mono.txt`.

The font files were sourced from the corresponding Fontsource packages. Font licenses are included alongside the files.
