Hardware & Software Requirements

PartialCAD has stronger hardware requirements for the graphics card than the classic exocad DentalCAD — a lot of data processing is done on the GPU.

  • A dedicated NVIDIA or AMD GPU with up-to-date drivers
  • Minimum 8 GB system RAM (16 GB+ recommended)
  • SSD storage for project files
  • Latest exocad DentalDB and PartialCAD license
ⓘ For full hardware specifications, consult the official exocad hardware requirements page.

Workflow Overview

PartialCAD uses a guided, wizard-based workflow. Click Next at the bottom of each step to proceed. Additional tools are available via the Expert icon on the right side of the screen.

Recommended Workflow Order

  1. Trim Scan
  2. Survey
  3. Edit Blockout
  4. Add Parts
  5. Draw Connector
  6. Mesh & Connector
  7. Bar
  8. Clone
  9. Finish Lines
  10. Apply Clasps
  11. Refine & Detail
  12. Save for Build
ⓘ The exact sequence depends on whether you are designing an upper, lower, or flexible partial. Upper partials go through Mesh & Connector; lower partials go through Bar first. Flexible partials skip connectors and go directly to Save for Build.

Case Setup in DentalDB

  1. Complete the prescription in DentalDB (client and patient name are required).
  2. Define one or more "Partial framework" teeth on one arch.
  3. For antagonist use, set up "Antagonist" in the opposing arch.
  4. Partial Frameworks can only be designed in one arch at a time — set up two cases for upper and lower.
  5. Scan as usual, then click Design or PartialCAD in the database to launch the CAD application.

1 Trim Scan Workflow

Remove unnecessary scan data before beginning the design. The input scan should only include the mesh under the partial framework plus any involved teeth.

ControlDescription
Select with BallPaint an area of mesh to be cropped or deleted.

EraserPaint-select an area to remove from the current selection.

⚠ Be careful not to cut any relevant areas when using the Plane selector. Use the view arrows (lower-right toolbar) to check from multiple angles.

2 Survey / Blockout Model Workflow

Specify the insertion direction of the partial relative to the scan data. The software displays undercut colors so you can evaluate and adjust the path of insertion.

Setting the Insertion Path

  • Left-click on the scan — the insertion arrow changes from white to red and the cursor becomes a 4-arrow cross.
  • Left-drag to rotate the model to the desired insertion path. Undercut colors update on release.
  • Set From View — rotate the model to the desired insertion angle and click this button.
  • Default Insertion — reset to the original Z-axis.

Blockout Parameters

ParameterDescription
Draft AngleDesired blockout wax draft angle (typically 2–3°). Zero degrees (default) may create tight frameworks.
Reduce ScanCut extra data from the bottom of the model. Use the slider to adjust the plane.
Block Out UndercutsUncheck to prevent any blockout from being done (rarely used).
ApplyGenerate a refractory model with light-blue "blockout wax" in the undercuts.
UndoCtrl+Z or the undo button to re-set parameters.

Undercut Depth Color Scale

Adjust the undercut color scale by left-clicking the bottom number of the scale to set the maximum value. The mid-scale adjusts accordingly.

3 Edit Blockout Workflow K

Expose undercuts in the blockout wax to define where retention elements (clasps) will go. The cursor is a ball-brush that you adjust with Q/W.

Smudge (Remove Blockout)

  • Left-click on blockout wax to remove it, exposing undercut color depth from Survey.
  • Keep the cursor moving in small circles or zig-zag for maximum effectiveness.
  • Adjust Tool Size and Wax Hardness sliders to control area and sensitivity.

Smooth Blockout

  • Normal — preserves blockout wax while smoothing.
  • Add — adds blockout wax during smoothing.
  • Remove — removes blockout wax during smoothing.
  • Smooth Level — adjusts smoothing strength within the tool area.

Additional Relief Wax

Stone models have sharp edges that scanners round off. If the partial doesn't seat properly, add a light blockout layer using Smooth in Add mode at moderate Smooth Level on sharp edges (rest seats, inter-proximal areas, bead line internal edges).

💡 Hotkeys: Alt+1 toggles smooth/smudge. Alt+2 normal, Alt+3 add, Alt+4 remove smooth.

4 Add Parts Workflow Y

Import and manage mesh objects in the current scene. PartialCAD auto-imports all mesh objects defined in DentalDB and designed in DentalCAD.

Importing Parts

  • Click Import to add an arbitrary mesh object file (.stl, .ply, etc.). The object must be pre-positioned relative to the scan data.
  • Each imported part appears in the Group Selector. Right-click to select; use Ctrl+right-click for multi-select.

5 Draw Connector Workflow D

Define curves on the refractory model that are used by many other tools. Open curves are used for lingual bars, clasps, and finish lines; closed curves are used for major connectors, meshes, and extraction sites.

Curve Drawing Controls

ControlDescription
DrawLeft-click on model/wax to create new curves. Double-click to end. Closed curves: double-click the first point.
ReplaceClick an existing curve and replace it with a new one.
EditSelect curves or control points. Drag to modify. Add points by clicking; delete by clicking + right-click.
💡 Use E to terminate a curve manually. Ctrl+Z to undo. For closed curves, if you miss the 2nd click on the start point, type E to end manually.

Workflow Variations

  • Upper Partials → Next: Mesh & Connector
  • Lower Partials → Next: Bar
  • Flexible Partials → Next: Save for Build

Draw Curves (Expert Mode) Expert

In Expert mode, the Draw Curves tool offers advanced options for curve fitting, line types, and junctions.

Curve Fitting Options

OptionDescription
Fit to Top SurfaceCurve fits to the top-most surface (scan data, blockout, or wax). When un-selected, the curve floats between control points — useful for lingual bars and finish lines above rough surfaces.
Fit to RefractoryCurve fits to the top-most surface of scan data or blockout, but beneath partial wax.
Fit to MeshDraws curves on scan data. Used to define virtual bead line prior to Survey.

Special Modes

  • Two Point — for straight, un-fit lines. Click once to start, once to end. Convenient for support bars.
  • T-Junction — connect curves at a "T" junction by selecting a point on an existing curve. Used for approach-arm clasps and multiple support bars.
  • Open Loop — prevents closed curves from being created. Useful for clasps, finish lines, and support bars.

Clasp Drawing Patterns

  • Ring clasps — single open curve, drawn from max support point to tip.
  • Akers clasps — single curve (tip-to-tip) or 2 curves (each from guide plane to tip).
  • "J" clasps — 2 curves: approach arm from solid support to transition, then from transition end to clasp tip.
  • "T" clasps — 2 or 3 curves: approach arm first, then tip-to-tip, or two curves from transition to each tip.

8 Clone (Fill in Wax) Workflow C

Apply rest seats, distal guide planes, and add material around the mesh to receive finish lines. The Clone tool adds a fixed thickness of wax.

Mouse Operations

  • Left-click & drag — add Clone wax.
  • Shift + Clone — remove a fixed thickness of material.
  • Ctrl + Clone — add on top of existing wax.
  • 1–5 — quickly switch between preset thicknesses.

Parameters

ParameterDescription
Tool SizeDiameter of the added wax. Use +/- or Shift+Scroll Wheel.
Wax ThicknessThickness of the added wax.
Settings → Bottom CutoffLimit clone to a specific part of the model using the slider.
PresetsAdditional thickness presets: Occlusal Rest / Lingual Rest / Minor Connector / Connector / Mesh.
Clone BlockoutHide wax and add blockout material to an area.
💡 Typical values: 1 mm for rest seats and guide planes; 1.75 mm to match the top of the mesh.

Smooth Expert V

General-purpose smoothing and wax editing tool with two modes.

Edit Wax — Smudge Mode

  • Smooth / Smudge toggle — switch between smoothing and removing wax.
  • Edit Blockout — switch to blockout editing.
  • Wax Only Mode — recommended only for editing the bottom part of the wax. Additive smooth when in wax-only mode to quickly smooth the partial.
  • Tool Size — brush diameter.
  • Wax Hardness — controls material removal sensitivity.

Edit Wax — Smooth Mode

  • Tool Size — brush diameter.
  • Smooth Level — overall smoothing strength.
  • Flatten Material — flatten surface within tool area.
  • Add Material — add wax during smoothing.
  • Remove Material — remove wax during smoothing.
  • Blend smoothly into Mask — smoother transition at mask edges.
💡 Alt+1 toggles smooth/smudge. Alt+2/3/4 changes flatten/add/remove modes.

Smudge Expert B

Smudge is accessed via the Smooth tool in Smudge mode. It removes (or adds) wax material interactively. Use left-click to remove, and keep the cursor in small circles or zig-zag motions for best results.

  • Adjust Tool Size with Q/W or Shift+Scroll Wheel.
  • Adjust Wax Hardness to control removal sensitivity.
  • Toggle between Smooth and Smudge with Alt+1.
